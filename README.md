# Caesar-Cipher
A simple desktop Caesar Cipher application built with Python and Tkinter.

Caesar Cipher is a lightweight desktop application for encoding and decoding text using the Caesar cipher.

The application is built with Python and Tkinter and features a dark terminal-inspired interface designed to keep the workflow simple and clear.

# Features

Encoding and decoding using a custom shift key

Support for uppercase and lowercase letters

Non-letter characters remain unchanged

Input limit of 10,000 characters

Numeric key with a maximum length of 7 digits

Copy and clear controls for input and output

Custom notifications and status indicators

Windows executable with a custom application icon

# Usage

Download the latest Windows executable from the Releases section and launch the application.

Enter the text you want to process in the Input field, enter a numeric shift key, then select Encode or Decode.

The processed text will appear in the Output field.

For example, using a shift key of 3:

HELLO → KHOOR

Decoding applies the reverse shift:

KHOOR → HELLO
