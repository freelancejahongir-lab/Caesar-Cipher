# Security Policy

### Supported Versions

Security updates are provided for the latest released version of Caesar Cipher.

| Version        | Support       |
| -------------- | ------------- |
| Latest release | Supported     |
| Older releases | Not supported |

## Reporting a Security Issue

If you discover a security vulnerability in Caesar Cipher, please report it privately instead of creating a public issue.

When reporting a vulnerability, provide the affected version, a clear description of the issue, steps required to reproduce it, and any additional information that may help with the investigation.

Please allow reasonable time for the issue to be reviewed and addressed before making the information public.

## Security Updates

Security fixes, when required, will be included in future releases and documented through the project's release history.
